# Global distribution assets

`world.geojson` is an unmodified snapshot of Apache ECharts examples:
https://github.com/apache/echarts-examples/blob/gh-pages/public/data/asset/geo/world.json

`echarts.bundle.txt` is the unmodified Apache ECharts 5.5.1 distribution:
https://github.com/apache/echarts/blob/5.5.1/dist/echarts.min.js

Apache License 2.0 is included in `world-LICENSE.txt`; original notices in the script and `echarts-NOTICE.txt` are retained. Assets are served from `/world.json` and `/echarts.js`.
